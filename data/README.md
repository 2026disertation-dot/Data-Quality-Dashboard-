# Data Directory

Every file here is either produced by the pipeline or kept as a fallback. All
of them are regenerated by `python run_pipeline.py`.

## Real data (the research evidence base)

| File | Produced by | Description |
|------|-------------|-------------|
| `kaggle_original_data.csv` | `download_kaggle_data.py` | Raw extracted EVM time-phase: one row per project x month x Portfolio WBS, carrying the **cumulative** planned value, actual cost and earned value. |
| `kaggle_cleaned_data.csv` | `clean_kaggle_data.py` | The same data converted to the dashboard's data contract: 8 projects, 76 monthly records, de-cumulated into period budget, period cost and period revenue claimed. |
| `kaggle_batch_data.csv` | `data_fixtures.py` | Historical split: every reporting period except each project's newest. Used for batch-mode testing. |
| `kaggle_incremental_data.csv` | `data_fixtures.py` | The newest reporting period of each project, representing the most recent cost records to have arrived. Used for incremental-mode testing. |
| `kaggle_anomaly_test_set.csv` | `data_fixtures.py` | Real records with a controlled set of labelled defects injected, for detection testing. |
| `kaggle_anomaly_ground_truth.csv` | `data_fixtures.py` | The injected defects, one row each, with the validation-engine key that should detect it. |

### A note on the anomaly test set

`kaggle_anomaly_test_set.csv` is for inspection. A genuine type error puts text
into a numeric column, so when pandas re-reads the file that **whole column**
comes back as text, exactly as a real dirty CSV behaves. That would make the
ground truth ambiguous, so the system tests build the fixtures in memory with
`data_fixtures.load_fixtures()` and use the CSV only for manual inspection.

## No synthetic fallback

Earlier versions shipped a synthetic generator (`generate_sample_data.py`) for
users without a Kaggle account. It has been removed: it produced numbers that did
not correspond to any real portfolio, and the reports are now measured on real
records only. Without Kaggle credentials, supply the dataset's 16 workbooks
locally instead:

```bash
python download_kaggle_data.py --local-dir C:/path/to/dataset
```
